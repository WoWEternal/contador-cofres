# Contador de cofres

Contador para Fortnite con atajos de teclado.

- Flecha arriba: suma 1
- Flecha abajo: resta 1
- Puedes escribir un número en "Cambiar a:" y pulsar Aplicar para continuar desde ahí.
- El valor se guarda automáticamente.

## Descargar

Ve a **Releases** (columna derecha del repositorio), abre la versión más reciente y descarga `ContadorCofres.exe`. No necesita instalación: haz doble clic.

No lee ni modifica el juego, solo detecta el teclado.
