# Contador de cofres

Contador para Fortnite con atajos de teclado.

- Flecha arriba: suma 1
- Flecha abajo: resta 1
- Puedes escribir un número en "Cambiar a:" y pulsar Aplicar para continuar desde ahí.
- Botón "Mostrar": abre un contador pequeño con el cofre y el número.
- El valor y la posición se guardan automáticamente.

## Fuente y plantilla

- `plantillas/`: imagen del cofre con la barra vacía en varios tamaños (30 % a 100 %). El tamaño se elige con el control deslizante de la ventana principal.
- `icono.ico` / `icono.png`: icono de la aplicación.
- `fuentes/`: coloca aquí `Retro Blendy.otf` (descárgala en dafont.com). Es gratis solo para uso personal, así que si subes el proyecto a GitHub, hazlo en un repositorio **privado** o no incluyas la fuente.

## Descargar

Ve a **Releases** (columna derecha del repositorio), abre la versión más reciente y descarga `ContadorCofres.exe`. No necesita instalación: haz doble clic.

No lee ni modifica el juego, solo detecta el teclado.
